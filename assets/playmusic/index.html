Fitur & Cakupan Proyek

  • queue_music

    Manajemen Library

    Pindai folder lokal, ekstrak metadata otomatis, dan kelompokkan berdasarkan artis/album.

  • graphic_eq

    Audio Equalizer

    Penyetelan frekuensi suara yang dapat diatur pengguna untuk pengalaman dengar maksimal.

  • lyrics

    Format Populer Mendukung

    Mendukung MP3, WAV, FLAC, dan format audio populer lainnya tanpa kendala.

  • pip

    Mini Player Mode

    Mode tampilan ringkas yang melayang di atas aplikasi lain saat sedang bekerja.
